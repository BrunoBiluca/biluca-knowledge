# go_router

> [!info] Referências
> [pub.dev](https://pub.dev/packages/go_router)
> [Documentação](https://pub.dev/documentation/go_router/latest/topics/Get%20started-topic.html)

A declarative routing package for Flutter that uses the Router API to provide a convenient, url-based API for navigating between different screens. You can define URL patterns, navigate using a URL, handle deep links, and a number of other navigation-related scenarios.

> [!example] Utilizado no projeto [[Projetos/Projeto - Biluca Finanças/Biluca Finanças|Biluca Finanças]]
> O go_router foi utilizado no projeto para gerenciar as rotas.
> 
> Foi principalmente útil por disponibilizar um ShellRoute e possibilitar ter uma barra lateral retrátil.
