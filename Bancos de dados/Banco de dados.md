## Tipo de banco de dados

- **SQL (relacional)**: para dados com relacionamentos complexos, transações [[ACID]] e consultas ad-hoc (ex: relatórios)
	- [[MySQL]]
	- [[SQL Server]]
	- [[Postgres]]
	- [[SQLite]]
    
- **NoSQL (ex: Cosmos DB)**: para dados com schema flexível, alta escalabilidade de escrita, e consultas por chave ou hierárquicas (ex: histórico de alterações, logs, eventos)
	- [[Elasticsearch]]
